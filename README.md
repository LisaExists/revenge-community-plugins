# LisaExists' Revenge Next Plugins

A personal plugin repository for Revenge Next, maintained by LisaExists.

## Included plugins

### [Hidden Channels (Next)](plugins/hidden-channels-next)

A Hidden Channels port for Revenge Next, featuring permission-aware detection, lock icons, and optional confirmation before opening hidden channels.

Version: **1.1.3**  
Plugin ID: `de.lisaexists.hidden-channels-next`

### [Decor (Next)](plugins/decor-next)

A port of the Vendetta Decor plugin. 

The Decor server is currently down

Version: **1.0.8**  
Plugin ID `de.lisaexists.decor-next`

## Build and publishing

Plugin source lives on `main`. The repository's release workflow builds plugin packages and publishes release ZIPs plus the generated `index.json` to `gh-pages`. Enable GitHub Pages for this repository using the `gh-pages` branch and root folder to serve the plugin index.
